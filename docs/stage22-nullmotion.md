# Null Motion fit for a DukaanSaathi launch video

Null Motion is a local motion-study tool that plays a finished ad above synchronized rough HyperFrames drafts and exports that **breakdown** as an MP4. It is useful for reviewing the structure and timing of a DukaanSaathi promotional film once a finished reference film or cut exists. It is not a video generator, and it does not create a finished ad from this app automatically.

The repository says it needs Node.js 22+ to run locally, Chrome or Edge to export, and optionally FFmpeg plus Python to import and prepare custom reference clips. Its server and bundled showcase require no API key or `npm install`. Custom footage would stay outside the application repository. The source is MIT licensed; bundled libraries and reference footage have separate terms.

Recommendation: use it later as a standalone storyboard and breakdown review tool for a short voice-to-verified-action launch film. Prepare original DukaanSaathi footage and draft beats first, then decide whether an exported breakdown is useful. Do not add it to the web app or treat its sample footage as our marketing asset.

Source: https://github.com/blixvip/NullMotion (README, inspected 2026-10-28).
